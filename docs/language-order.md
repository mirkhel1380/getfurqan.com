# Language menu order

Language lists place English first, Dari second and Pashto third when those
editions exist; other languages retain their previous relative order. This
applies to Quran translation choices/cards, search, tafsir, word meanings,
Quran duas, shared header/footer shortcuts and Hadith translation menus.
Shared Quran shortcuts now include the existing Pashto translation.

Existing selected/default editions are preserved. Tafsir does not gain a
separate Dari edition: English and Pashto precede the existing Persian edition.
No source text, source attribution, Arabic content or edition IDs are changed.
