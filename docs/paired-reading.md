# Paired ayah reading

Reader verses and translation views retain the original Arabic ayah on the right and its matching translation on the left. Arabic-only view is unchanged. At widths up to 1100px, each ayah stacks directly above its own translation.

The study page places the existing selected-verse panel beside the tafsir or word-meaning panel, stacking at 900px. On wider screens the ayah stays in view while the explanation scrolls, with its own overflow for unusually long verses. All source text, edition selectors, verse references, source range labels, loading/error states and controls remain unchanged. No source text or API rendering code was edited.
