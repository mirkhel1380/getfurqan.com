# Al Furqan

Buildless Quran website. Static assets are in `dist/`. Intended domain: getfurqan.com.

The reader supports surah, verse, juz and Madani page navigation; Uthmani, IndoPak and Tajweed rendering; Dari (Muhammad Anwar Badakhshani), Persian (IslamHouse) and English (Saheeh International) translations via QuranEnc; verse-by-verse recitation via the Quran.com API; local bookmarks, reading modes, size settings and light/dark themes.

Quran data and fonts: Quran.Foundation. Translations: QuranEnc, credited per edition. No Quran or translation text is generated or manually rewritten. Source services and fonts require network access. All content is fetched at runtime.

Independent text comparison and qualified Quran proofreading remain pending. This is a development preview, not a certified Mushaf. Bookmarks/preferences are local to the browser; no account or cross-device sync is implemented. Custom domain is not connected.

Validation: JavaScript syntax; browser checks of three translations, Tajweed light/dark, Uthmani/IndoPak, surah pagination, page 604, Juz 30, direct verse navigation, local bookmarks, continuous Arabic view and live audio playback. This does not establish full-corpus text accuracy.
